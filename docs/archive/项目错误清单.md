## 四、教训沉淀（写给未来的自己）

1. 复用已验证代码**逐字拷贝，不许默写**（三次应验：calc_features、v4 门控、解析过滤器）；
2. 任何改标签/改数据的操作后面**必须跟生效断言**（与预期值对不上就 raise）——三次拦截毒数据；
3. CV/验证指标异常 = 数据在报警，**先看明细再报喜**；
4. 不猜字段名/布局/协议，**先探针后解析**；
5. 修复版**文件名带版本号**，运行输出**打印版本号自证**；
6. 对论文数字的每个对比都要先问：**口径一致吗？**
