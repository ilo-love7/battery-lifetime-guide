## 主结果 A1-A4

共享加载器实测续跑标签为 `[1851, 2159, 2236, 1433, 1708]`，断言通过；官方开发池 84 颗，训练 41 颗、测试 43 颗。所有调参和特征组选择只在训练池四折 CV 内进行，所有候选在固定测试池统一评估一次。bootstrap 对测试电池有放回重采样 10,000 次，比较使用逐电池配对中位误差差值；改善至少 2pp 且 CI 排除零才记为“优于”。

## 迁移与生存结果

| 实验 | 结果 |
|---|---|
| B1 EN 零样本 | 三例中位误差 9087.6%；z-score 374.3%，CORAL 495.1%。重标定后仍不可用；NASA 的 18/18 个特征值超出 MIT dev 的 P05-P95。 |
| B2 EN few-shot | 三折留一、每折两例拟合校准器，中位误差 27.4%，bootstrap CI [20.2,316.8]。结果仅探索性。 |
| B3 Weibull AFT | shape=2.872、scale=179.3 圈、中位估计 157.8 圈；KM 中位数 125 圈。Weibull/KM 的 10,000 次 bootstrap 95% CI 分别为 [102.4,+∞] / [97,+∞]，模型没有缩窄不确定性。11 颗删失样本另输出条件 p10/中位/p90 寿命。 |
| KM 独立验证 | 既有手写 KM 与 lifelines 逐点最大差 1.11e-16，中位数均为 125 圈。 |

B1 的重标定用三颗目标电池的无标签特征，因此是 transductive 设定；B2 使用留出电池标签只作最终评估。三例 bootstrap 区间高度离散，不外推为一般迁移规律。

## 结果产物与复跑

仓库内 `results/optimization_v1/` 为本次核验快照；按本机配置重跑时，结果默认写入被忽略的 `results/generated/optimization_v1/`。`main/` 含 CV、逐颗预测、区间和结论；`transfer/` 含迁移方法比较与逐颗预测；`survival/` 含 AFT 参数、删失预测、曲线比较和结论。

在项目根目录运行：

```powershell
Copy-Item config.example.toml config.toml
python scripts/run_project.py --show-paths
python scripts/run_project.py --stage quick
python scripts/run_project.py --stage optimization
python -m pytest tests -q
```
