## 关键结论

- 官方 MIT 开发池为 84 颗，固定划分为训练 41、测试 43；续跑合并标签断言通过。
- EN6 官方测试中位误差为 5.9%，bootstrap 95% CI [5.1,8.9]；论文报告点估计 9.1%，论文侧无可比 CI/逐颗误差，因此只称“点估计接近，统计差异未定”，不称统计一致或优于。
- NASA 34 颗全量审计：标准 3、删失 11、中断井 11、从未满充 7、样本过少 1、边界 1。B0033 依 5d 决议按边界处理，不进入迁移/KM。
- 迁移结论限定为 B0005/B0006/B0018 三个案例；step6 重标定和 few-shot 结果均属探索性，Weibull/KM bootstrap 上界无穷，不声称缩窄了不确定性。

## 兄弟仓库互证（2026-10-18 节选）

- 受控实验（对方 `scripts/verify_en_l1ratio.py`，本仓特征快照 × 对方名单划分）：
  固定 `l1_ratio=0.5` → 6.18%，双参搜索 → 6.04%（只差 0.14 pp）；换特征数值定义
  6.18% → 8.33%。结论：2.4 pp 主因在特征管线，不在超参。
- 逐颗核验：主测试 43 颗成员完全一致；寿命标签仅 3 颗续跑电池差 1 圈；124 颗名单对上；
  ΔQ 六特征数值定义 diff 尚未做。**2026-10-18 数据已就绪**（`mit_dir` → `D:/项目/02_数据集/01_国际公开集/MIT_MATR-1/原始数据`，8.27 GB），升格为可执行项。
- 连带修正：RF 8.2% vs 8.12% 的「完全一致」是不同特征集的巧合；同口径对照为
  对方 paper6 RF 9.38% vs 本攻略 8.2%（同向差约 1.2 pp）。
- 对方显著性补测（bootstrap + Wilcoxon）：n=43 下 GBM 6.20% vs EN 7.77% 不显著
  （p=0.93），与本攻略「不宣称统计一致」纪律互为印证。

## GitHub 可复现入口

- `python scripts/run_project.py --stage quick`：无原始数据的教学演示。
- `python scripts/run_project.py --stage paper`：复现官方 MIT 结果，需要 MIT 三个 `.mat` 文件。
- `python scripts/run_project.py --stage extensions`：NASA 全量审计、迁移拆账和 KM，需要完整 34 个 NASA `.mat` 文件。
- `python scripts/run_project.py --stage optimization`：MIT 优化与三颗标准 NASA 迁移/生存实验。
- `python scripts/run_project.py --stage full --dry-run`：检查完整阶段编排，不读取数据。

数据路径用 `config.example.toml` 复制为本机 `config.toml`，或设置 `BATTERY_MIT_DIR`、`BATTERY_NASA_DIR`、`BATTERY_CACHE_DIR`、`BATTERY_OUTPUT_DIR`。原始数据、本机配置、缓存和 `results/generated/` 不应提交。
