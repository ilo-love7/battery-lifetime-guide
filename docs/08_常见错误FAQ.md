# 08 常见错误 FAQ：症状 → 根因速查表

> 卡住时先来对症状。完整现场还原在 docs/05；带 bug 的原始代码在 docs/buggy_注释版/。

## 一、报错类

| 症状（报错/表现） | 大概率根因 | 速查修复 | 详见 |
|---|---|---|---|
| `KeyError: no field of name 'xxx'` | 猜字段名（单复数/大小写） | 打印实际字段清单，动态探测 | 05 案例 6 |
| `KeyError: ['slope', 'intercept', ...]` | 改造代码时漏算部分特征列 | 特征清单做成断言 `D[FEATURES]` | 05 案例 10 |
| `ValueError: shapes (1000,) vs (471,)` | 拿错数组（容量序列 vs 电压曲线） | 确认"N 的单位"，数组形状即断言 | 05 案例 9 |
| `UnicodeDecodeError: 'gbk' codec ... 0x94` | 中文 Windows + 库内部读文件默认 GBK | `sklearn.set_config(display="text")` | 05 案例 4 |
| `TypeError: xxx is an unexpected keyword` | 库版本变更删了参数 | 最小参数集；对照版本文档 | 05 案例 12 |
| `FileNotFoundError` 且路径"明明对" | 瞎猜数据布局 | 先探针后解析，路径写死真实值 | 05 案例 13 |
| `NameError` 依赖上一次会话的变量 | 脚本不自包含 | 新窗口从头跑通才算完成 | 05 案例 14 |
| 图全空白但无报错 | 取到空数组（索引语义错） | 检查"第 N 个"的计数口径 | 05 案例 7 |

## 二、不报错但结果不对（更危险）

| 症状 | 大概率根因 | 速查修复 | 详见 |
|---|---|---|---|
| 诊断打印全 ✓，下游用旧数据 | `iterrows()` 副本写不回 | 查表存索引，`feat_df.at/loc[mask]` 写回 | 05 案例 2 |
| 某批实体标签集体变成极值 | 扫描起点撞占位值（如 0 Ah 占位圈） | 跳过占位 + 连续 N 点判定 + 生效断言 | 05 案例 1 |
| 结果"变好了"但 CV 指标异动 | 毒数据在报警（先变好 later 变毒） | 先看明细再报喜，断言锁住关键值 | 05 案例 1 |
| 模型预测值扎堆在某下限附近 | 地板效应（RF 不外推）+ 测试分布越界 | 换可外推模型或正视分布差 | 05 案例 1 / 02 §2.6 |
| 训练池数量差几颗（89 vs 84） | 漏剔官方中止/截断实体 | 官方剔除=数据质量闸，`assert len()==期望值` | 05 案例 9 |
| 分类结果与上一版不符 | 过滤器阈值跨数据集复用未审 | 每个阈值重新审问；变量逐颗重置 | 05 案例 11 |
| 跨数据集误差 ×几十~上百 | 域间隙（协议/体系本征差异） | 逐层证据链 + 可证伪拆账 | 04 §5b/5c |
| 数字与文献对不上 | 考卷口径不同（划分方式/EOL/窗口） | 先对齐口径再谈复现 | 05 案例 3 |

## 三、流程类

| 症状 | 大概率根因 | 速查修复 | 详见 |
|---|---|---|---|
| 大文件解析"卡死" | 静默≠卡死；重跑堆积内核 | pickle 缓存 + 进度 flush + 杀干净再跑 | 05 案例 5 |
| 排查半天发现是"想当然" | 锚点/预期未经交叉验证 | 管线与锚点两边独立核查 | 05 案例 15/16 |
| 协作者说"没看到你的修改" | 挂载/快照 ≠ 双向同步 | 先做写读回环验证；交付物显式打包 | 05 案例 17 |
